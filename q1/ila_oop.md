# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

how the concept can be used in the sari-sari store inventory system
what data, object, property or method may be involved
how applying the concept can improve the organization or design of the program.

### 1. Encapsulation
By bundling data like all the information of an item can be put into one product, which its data is protected, but can be accessed by store clerks and managers. 
The object can be the product itself. We can have methods of handling the data like by creating functions.
By applying this concept in a program, we can make it easier to change methods all inside one product.

### 2. Abstraction
By only giving out the necessary outputs needed by the employees, we are to not show the details like how the store stores products.
Methods like restock can be used to maintain stock, but it does not need to know where the stock comes from.
Through this, we can increase privacy and lessen complexity.

### 3. Inheritance
When a method is reused many times, it is deemed to be useful, which can also be used in different methods too.
By having a method that counts stocks, we can use this on other methods like restock and tracking expenses.
Thus, we make it easier for others to visualize the program, as for less program syntax, and more of a logical term of perspective.

### 4. Polymorphism
We can use a specific method like counting stock differently according to specific types.
A method that counts stock, can be used to count juice by 10s if we are counting juice boxes.
This makes it more efficient to recognize the various types of stocks in the system.
