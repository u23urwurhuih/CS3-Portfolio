# SG4 - Understanding Classes and Objects
## Context - School Bag

## Class Name - Calculator
## Class Description
- My class represents a calculator, which has data. It has attributes of brand, price, and low battery; it has a method to calculate.

## Properties
| Property | Data Type | Description |
| brand    | str       | The brand where the calculator is from|
| price    | int       | How much the calculator is costed about|
| lowbattery | boolean | If the calculator is low or high in battery|

## Methods
| Method | Description |
| calculate | Allows a user to compute for expressions in math |

## Design Explanation
### Why did you choose this class?
- As this class is a common item found in school bags, which students use scientifically for math and physics, so the calculator can compute for the values automatically.
### Which property is the most important? Why?
- lowbattery, as this property determines if the calculator will function or not due to its battery percentage.
### Which method is the most useful? Why?
- calculate, as this is the sole purpose of the calculator upon use.
